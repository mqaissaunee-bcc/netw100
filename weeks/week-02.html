Explore

Six role families

Most IT and cyber jobs fall into one of these families. Many people move between them over a career.

Support

Help desk, desktop support, IT technician. First responders for people with tech problems. The most common entry point into the whole field.

Networking

Network technician, network admin, network engineer. Build and run the connections between devices, buildings, and clouds.

Security operations

SOC analyst, incident responder, threat hunter. Watch for attacks and respond when they happen.

Cloud and systems

Systems admin, cloud engineer, DevOps engineer. Run servers and cloud platforms, often by writing code to automate them.

Governance, risk, and compliance

GRC analyst, IT auditor, compliance specialist. Make sure the organization follows rules and manages risk.

Management

IT manager, security manager, CISO. Lead teams, budgets, and strategy. Usually reached after years in another family.

A day in the life

Help desk technician

Starts the shift by checking the ticket queue. Resets a locked account, walks someone through connecting to the VPN, replaces a failing laptop battery, and escalates a server problem to the systems team. Spends a lot of the day talking to people, so communication matters as much as technical skill.

Network administrator

Reviews overnight alerts on network devices, adds a new switch for an office expansion, adjusts Wi-Fi coverage in a conference room, and plans a firmware update for the weekend maintenance window.

SOC analyst (Tier 1)

Works a queue of security alerts. Decides which are false alarms, which need more digging, and which to escalate. Documents everything. Many SOCs run 24/7, so shifts can include nights or weekends early in a career.

Cloud engineer

Writes templates that build cloud servers automatically, tunes costs, fixes a broken deployment, and meets with developers about a new application. Usually reached after support or systems experience.

Entry, mid, senior

Careers usually grow in stages. Entry-level roles (0–2 years) follow procedures and escalate hard problems. Mid-career roles (3–7 years) own systems and solve the hard problems. Senior roles design, lead, and set direction. CyberSeek calls the roles that lead into cybersecurity feeder roles, and help desk and network jobs are the biggest feeders.
